Oscillometric Method

The oscillometric method detects blood pressure by analyzing pressure oscillations in the cuff during controlled deflation. The Maximum Amplitude Oscillation (MAO) corresponds to MAP. SYS and DIA are derived from characteristic ratios of the MAO envelope.

SYS Ratio 0.55 × MAO
DIA Ratio 0.85 × MAO

📐 Analog Front End

Low-noise analog front end using AD620 instrumentation amplifier (G ≈ 105) and TLC2272 for ~1.5V reference offset. Designed for millivolt bridge sensors like MPS20N0040D.

Gain ≈ 105
RF Filter ~340 kHz
LPF ~2.35 kHz
Offset ~1.5V

🔬 Sensor & Components

MPS20N0040D

Millivolt-level bridge sensor (≈50–100 mV full-scale; 4–6 kΩ). Commonly used in hobbyist sphygmomanometers.

AD620

Instrumentation amplifier. Relatively cheap and widely available. RG = 470Ω → G ≈ 105.

TLC2272

Dual, low-noise, rail-to-rail operational amplifier for reference voltage offset generation.

STM32F411CE

The "Black Pill" — digital processor/controller for ADC sampling and signal processing.

🏗️ Complete Device

Retrofitted pump system with blood pressure cuff, electronic control, and analog signal conditioning.

⚠️ Safety Notes

  • MPS20N0040D is fragile — avoid over-pressure
  • If powering from USB, beware ground noise from the host PC
  • A ferrite on the USB cable can help reduce noise
  • This web tool is for educational purposes only — not medical advice
